# Knowledge Spaces and Layered Memory

## Spaces
Search may weight personal, project, and shared spaces differently. Space weights are ablation hyperparameters, not fixed product rules.

## Layered Memory
Agent memory layers include profile, journal, and project notes. Updates supersede previous entries without physical deletion so rollbacks remain possible.

## Distillation
Optionally, a finished run can be distilled into a short note and re-indexed into the knowledge base for future retrieval.
